# In-session scratchpads

Temporary working notes for resuming a session or handing findings between agents. The [session index](../sessions/README.md) links each session summary, which links its scratchpad. Create `<session-id>.md` from [TEMPLATE.md](TEMPLATE.md) when useful.

Use dated, owned entries with confirmed facts, hypotheses, work in progress and next actions. If multiple authorized agents are involved, each owns its own section or `<session-id>-<agent>.md`; the coordinating agent consolidates the summary. Do not overwrite another agent's live notes.

Before finishing, promote durable information to canonical docs and the session summary. Mark the scratchpad closed and link its summary. Closed scratchpads are historical context, not current instructions. Keep secrets, copied bulk logs and generated binaries out of this directory.
